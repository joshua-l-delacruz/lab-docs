# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the public portfolio deployment.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature under **Security → Advisories → Report a vulnerability**. Do not open a public issue containing exploitable details, credentials, personal information, employer material, tenant identifiers, private property records, or production logs.

Ordinary rendering, accessibility, and content defects can use the public portfolio bug form.

## Scope

Useful reports include Cloudflare Worker authorization or owner-isolation weaknesses, unsafe proxy behavior, exposure of D1 records, missing browser security controls, origin confusion, and unintended disclosure of personal or operational data.
